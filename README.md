# kuma-develop/level
EXP + levels for Flarum 2.0 / EXP và cấp độ cho Flarum 2.0. No Node.js needed (JS is prebuilt in js/dist).

Languages / Ngôn ngữ: English (en), Tiếng Việt (vi) — locale/en.yml, locale/vi.yml. Other locales fall back to English.

- Admin > Levels: EXP per action, toggle icons, add/edit/delete levels (name, min EXP, icon, color).
- Admin edits a user's level: profile > moderation menu > "Edit level".
- Default level names follow the user's language; a name typed by the admin overrides it in all languages.
- Level-up notification: bell alert when a user reaches a higher level; admin toggle in Admin > Levels; users can opt out in Settings > Notifications.
